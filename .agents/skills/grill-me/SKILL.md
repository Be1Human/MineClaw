# Design Challenge

Use this skill before a risky or cross-module change.

Question the proposal from independent angles: user goal, architecture boundary, state ownership, failure handling, observability, security, migration, rollback, and testability. Resolve one decision branch at a time and record the answer that changes implementation scope.

Finish with a concise decision log: accepted assumptions, rejected alternatives, unresolved questions, and objective acceptance criteria. Do not begin implementation while a high-impact decision is still ambiguous.
