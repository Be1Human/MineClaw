# MineClaw Public Skill Catalog

These skills describe reusable, public-safe development workflows. They do not contain credentials, private server addresses, local workspace paths, or hidden operational state.

| Skill | Use it for |
| --- | --- |
| `clawpm-project-workflow` | Planning, claiming, testing, and accepting work recorded in `.clawpm`. |
| `doc-style` | Writing clear requirements, designs, and test documentation. |
| `framework-first-debugging` | Diagnosing behavior across the full runtime flow. |
| `grill-me` | Stress-testing a design before implementation. |
| `local-loop-test` | Running a safe local build-to-observation validation loop. |
| `memory-benchmark` | Exercising the checked-in memory benchmark without external model spend. |
| `minecraft-test-environment` | Preparing an explicitly configured local Minecraft test environment. |
| `requirement-intake` | Recording a new feature or defect before implementation. |
| `run` | Starting the backend and local control console. |
| `test-doc` | Capturing reproducible test cases and reports. |

The skills are guidance, not a substitute for repository policy. [AGENTS.md](../AGENTS.md) and `.clawpm/AGENTS.md` take precedence when they apply.
