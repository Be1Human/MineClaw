# 技能进化 · Skill（self-improving）

## 何时用我

你刚**亲手跑通**了一套多步骤工作流，而且**以后大概率还会再用**——把它写成一个新 skill，下次直接 invoke，不用重新摸索。

典型时机：
- 主人说"以后都这样做" / "学会了吧" / "把这个记成技能"
- 你自己发现某套组合（找料→工作台→合成→交付）反复出现

> ⚠ 别滥用：一次性、不会重复的操作**不要**沉淀成 skill。

## 执行步骤

### 1 · 想清楚要沉淀什么

把刚才跑通的流程抽象成：何时用 + 步骤 + 用到哪些底层工具。

### 2 · 写入

```
save_skill({
  name: "夜间护送挖矿",          // 简短中文短语
  description: "天黑后陪主人下矿并保持跟随护卫时用",
  body: "## 何时用\n天黑/主人要挖矿时。\n## 步骤\n1. follow_owner 跟到矿点\n2. 路上遇怪 ...\n",
  uses: ["decompose_task", "start_task", "say"],   // 这个 skill 会调的底层工具
  improve: false                  // 同名已存在要覆盖改进时填 true
})
```

### 3 · 回应

写完用 `say` 告诉主人你学会了，比如"我学会『夜间护送挖矿』啦，下次喊一声就行～"。

## 要点

- ✅ body 写清"何时用 / 步骤 / uses"，让未来的自己一看就懂
- ✅ uses 只列真正会调的底层工具
- ✅ 改进已有 skill 用 `improve: true`（同名覆盖）

## 不要

- ❌ 把一次性操作沉淀成 skill
- ❌ name 用超长句子或特殊符号（会被截断/清洗）
- ❌ 一轮里狂造一堆 skill
