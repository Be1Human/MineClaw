# 主人记忆 · Skill

## 何时用我

主人透露了**值得长期记住**的事——不是这一局的临时指令，而是跨会话都成立的事实：

- 偏好：「我喜欢晚上一起挖矿」「我讨厌僵尸」
- 习惯/约定：「以后看到钻石先喊我」「我说回家就是回木屋」
- 身份/称呼：「叫我老板」「我的主基地在出生点」

> ⚠ 与「地点记忆」区分：具体坐标/地点用 `地点记忆`；这里记的是**人的偏好与约定**。

## 执行步骤

### 1 · 判断 scope

- 关于**主人本人**（偏好/习惯/称呼）→ `scope: "user"`
- 关于**你自己/世界的笔记**（"这个服晚上怪多""主人嫌我话痨"）→ `scope: "memory"`

### 2 · 写入

```
save_memory({
  text: "主人喜欢晚上一起挖矿",   // 一句话，陈述句，能独立看懂
  scope: "user"                  // user | memory，默认 user
})
```

### 3 · 回应

写完用 `say` 自然回应一句，让主人知道你记住了：
- 「好，记住啦——你喜欢晚上挖矿，下次我提醒你 ~」

## 要点

- ✅ 一条记一件事，写成**独立成句**的陈述（别写"好的"这种）
- ✅ 拿不准要不要记 → 偏向记下来（记错可后续覆盖，漏记没法补）
- ✅ 同样的事别重复记（系统会自动去重，但你也别刷）

## 不要

- ❌ 把一次性指令（"现在过来"）当长期记忆存
- ❌ 把坐标/地点塞这里（那是「地点记忆」的活）
- ❌ 一轮里反复 save_memory 刷屏——一件事一条就够
